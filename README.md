# Static Site File Generator

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)

A small Python script that creates a starter website directory with an HTML page, stylesheet, 404 page, and `robots.txt` file.

## Generate the starter site

```bash
python site.py
```

The script creates the files in a `website/` directory. Open or edit the generated HTML and CSS to customize the page.
